# Investigation and implementation

Workspace cleanup note: historical paths below describe the audited runs. The source image is now a standalone top-level file, the library is in `data/library`, unique archived annotations are in `data/annotation_history`, and compact current/legacy reference outputs are in `reports/reference_run` and `reports/legacy_reference`. Duplicate application folders, ZIPs and regenerable large outputs were removed. See `workspace_cleanup.json` for the inventory and the project README for current rebuild commands.

This audit covers the top-level manual annotator, the archived `annotation_app_2.1` copy, the existing automated pipeline, the annotations and saved models, and the supplied implementation plan. The implemented production path uses one barcode per nucleus and a configurable 55 px analysis diameter, as confirmed by the assay owner. The production library is `barcode_new`, following the owner's clarification that the original barcodes were replaced after a check. The physical synthesized library identity remains an experimental provenance fact, rather than something the software can prove.

## What the manual annotator actually measures

The supplied file contains thirteen 16-bit RGB pages, shaped `(13, 5340, 5998, 3)`. Page zero is phenotype/cycle zero; pages one through twelve contain SBS cycles. Red is RGB channel zero, green channel one, DAPI channel two. The stored values are used directly; UI LUT minimum, maximum, color and brightness settings are downstream rendering choices. We cannot infer whether any earlier image-export step transformed those stored values.

A requested nucleus coordinate determines a local crop with radius `max(24, round(diameter * 1.6 / 2))`, normally 44 px. For each cycle, local DAPI Otsu segmentation and hole filling identify the nuclear object nearest the requested center; if its centroid is within the requested nuclear radius, the circle moves to that centroid. The analysis mask is a circle, not the organic DAPI contour. Cycle-zero DAPI is the fallback when current-cycle DAPI lacks contrast. The shared implementation preserves this distinction and the same edge-clipped crop behavior.

Each channel is detected separately after sigma-one Gaussian smoothing. Background and noise come from the lower 40% of smoothed pixels inside the analysis circle, followed by median and 1.4826 times median absolute deviation. This is not simply the median of all nuclear pixels. The detector requires peak excess, SNR, nuclear 95th-percentile excess, and a fold change. The actual UI defaults are green excess 3,500 counts, red excess 650, effective peak SNR 4, 95th-percentile excess 400, and fold change 2. A candidate grows above the larger of `background + 0.28 * peak_excess` and `background + 3 * noise`. It retains the connected component containing the peak, closes its boundary, and requires area at least six pixels and at most 60% of the sampling circle. The historic low-threshold argument does not implement hysteresis in this detector.

The base feature extractor measures each channel in its own detected mask. If that channel has no mask, it uses the detected red/green union when available, otherwise the sampling circle. Its background is the median of nuclear pixels outside the evaluation region, falling back to the evaluation region when no outside region exists. This is a distinct estimator from the detector's lower-tail background. Distributions contain extrema, quantiles, mean, standard deviation, IQR, upper-core statistics, the mean over the 50th–90th-percentile window, nuclear reference median, median excess, integrated excess, a 32-bin histogram, and representative pixel samples. Cross-channel ratios and spatial features are retained. The shared code keeps these exact choices rather than replacing them with a different definition of “intensity.”

The blob validation features combine the channel masks and their local z-score energy, with area, fraction of circle occupied, shape, boundary distance, saturation and raw per-channel photometric features. Its persistence feature is constant one for these single-cycle annotations. Its integrated “excess” feature historically sums energy rather than raw intensity excess; the old automated implementation used a different quantity under the same name. The shared implementation eliminates that mismatch. The detailed manual audit is in `../audit_manual.md`.

## Confirmed failures in the previous automated path

The previous pipeline constructed full-image background/noise maps, positive z scores, a top-three-cycle energy aggregate and persistence-weighted detection image, then segmented it with hysteresis inside the DAPI masks. Its background is a coarse downsampled spatial median, while its noise includes a global residual-MAD estimate. Calling this a single global slide median is inaccurate. It nevertheless produced extensive nuclear-sized components that the 95%-of-nucleus filter rejected.

That rejection can be verified without rerunning enormous image-wide intermediates. The archived probability map is a monotonic sigmoid of the detection image. Transforming the saved high/low thresholds into probability space and applying the original segmentation rules reproduces the saved component mask with zero differing pixels. There were 4,597 oversized rejected components in 4,597 nuclei; sixteen of those nuclei also retained another component. Consequently 4,581 nuclei lost every candidate. The surviving 896 components occupied 797 nuclei. `legacy_detection_audit.json` records the reconstruction and its assumptions. Exact mask agreement corroborates the configuration because the old run did not save a complete manifest.

The saved nucleus/component tables in this workspace contain zero accepted assignments: every surviving component was rejected by the saved classifier, with maximum probability below 0.485. Thus the quoted later count of 558 mappings cannot be reproduced from these particular saved files. It may come from a different run or threshold. We preserve the original output rather than treating that number as verified baseline data.

The classifier was also given incompatible features: pooled cross-cycle measurements instead of per-cycle annotator measurements; always-false channel-detected indicators and zero channel areas; zero DAPI-under-blob measurements; and an area fraction in place of the annotator's distance-based ownership ratio. Base calling measured both channels inside a pooled component mask, omitting their independent masks. Merely replacing the background estimator would leave these model-input errors intact.

Most seriously, both historical label conversions were wrong. “Both channels called correctly” does not mean both contain real signals, and “at least one channel called correctly” does not mean some signal exists. For each channel the true presence is `original_detected == called_correctly`. Applying that truth table yields 172 positive and 209 negative blob-annotation cycles; 154 of 381 existing `is_real_blob` values disagree. The original detection bits are essential: they are used before feature regeneration, never replaced with the new detector's bits for label derivation. Original CSVs remain unchanged.

## Assessment of the proposed plan

The local detector and faster vectorized decoder were sound directions. The label repair `call_status != neither` would have preserved a major error, and the promise of no further ground-truth work was too strong. The 1,776 examples are base-annotation rows, not 1,776 independent blob examples. There are 381 blob rows and 1,760 usable base rows after excluding sixteen Ns.

The quoted area measurements are correct: 193 blob rows have area above 300 px, eighty above 600, and the maximum is 1,280. For nonzero masks, area divided by the saved fraction has median 2,375.19 px, equivalent-circle diameter 54.99 px. The fraction was rounded to three decimals. This approximately reconstructs a sampling area, not an exact historic diameter, center, biological nuclear boundary, or all settings. Zero-area rows cannot recover it at all. The DAPI segmentation median area is about 1,238 px, or 39.7 px equivalent diameter, which measures a different object. Treating either circle as definitive biological nuclear ground truth would be unjustified.

Dropping area and fraction alone would not remove diameter dependence: diameter changes the sampled pixels and therefore background, noise, quantiles, mask selection and spatial features. We regenerated features at a declared 55 px setting and preserve all features with compatible training/inference provenance. There is no new hard 250- or 350-pixel spot-size ceiling. The large annotated spots are not discarded by such an invented limit.

The old backup's extreme contrast row is a normalized z-score, not 1.3 million raw intensity counts. A tiny noise denominator can make it very large. Its magnitude alone does not establish corruption; raw feature regeneration is preferable to deleting it. The current CSV's value was already different from the backup. No source row was silently removed on that basis.

Finally, expected candidate counts of 1,200–2,000 and promised 0–1 mismatches were not validation criteria. Thresholds were not selected to hit a requested count or force observations into the library.

## Implemented behavior

`popcrop/annotation/analysis.py` is used by both the application and the default automated path. Every segmented nucleus is evaluated in every cycle, using raw intensity, independent channel masks, the 55 px circle, current-cycle DAPI, the same fallback and complete spatial context. No image-wide illumination correction, background subtraction, unmixing or resampling enters the trained features. Model metadata rejects incompatible feature versions, model targets, channel classes, diameter or detector settings.

The base caller evaluates even detector-negative cycles. This matters because six true-positive blob annotations have no detector mask and a collapsed blob feature vector; gating the whole nucleus with that vector would erase recoverable observations. The corrected blob model scores each cycle and its results remain in the output as independent diagnostic evidence. Signal presence is the base model's combined P(A)+P(C)+P(T) at a declared threshold of 0.70. All observations and probabilities remain available, rather than being overwritten when a nucleus is classified negative.

Barcode observations are immutable hard calls with the specified A/T/C/G mapping. Ties become N and Ns are excluded from assignment. Reverse complementation is applied once when comparing with the library. Likelihood ranking is vectorized, confidence is normalized over every unique reference sequence, and both nearest-Hamming and likelihood-selected distances are reported. A selected sequence must pass the explicit distance, margin and relative-support requirements. Duplicate barcode sequences share one likelihood hypothesis and retain every gene candidate. Nine `barcode_new` sequences collide between two genes each; these cannot be uniquely gene-assigned.

TIFF loading is file-backed and retains the original integer values. Feature computation uses small local crops and bounded inference batches. The full-resolution biological mask, diagnostic union masks, and exact per-cycle masks are preserved. Histograms and sample representations are retained even though the current models use their scalar feature summaries. Parquet and TIFF outputs use lossless compression, and a dependency lock, model hashes, settings and runtime records support reproducibility. Original annotation files, models, archived app and output remain available.

Future UI annotations save their exact analysis settings, raw-image fingerprint, coordinates, diameter, sampling area and detector state. Features come from the server's actual displayed analysis rather than unverified client values. LUT changes do not invalidate scientific analysis or alter recorded raw intensities.

## Validation and interpretation

Calibration and heldout splitting keep all cycles from a nucleus together. On 335 heldout base rows from 307 nuclei, accuracy is 94.93%, balanced accuracy 93.75%. At independently generated DAPI centers, the same heldout model achieves 94.33%, balanced accuracy 93.05%. Every heldout row matched an automated nucleus within 27.5 px, with no training/test identity aliases. This directly checks transfer from the annotation coordinates to automated segmentation coordinates.

For corrected blob presence, the heldout set has 77 nuclei: 39 true negatives, 35 true positives, three false negatives and zero false positives at the declared 0.70 threshold; accuracy is 96.10% and ROC AUC 0.9845. On 323 recovered blob-derived bases from nuclei absent from the base model's fitting groups, base accuracy is 92.88%. The base model was trained on explicit base annotations only because the two annotation tasks include a conflicting overlapping label.

Only nine nuclei have complete twelve-cycle manual reads. The deployed model reproduces all 108 annotated bases, but it has been refitted on those annotations, so this is a reconstruction/parity check. Only one complete read lies in the independent heldout split, and all twelve bases match there. The manually annotated reads themselves have nearest-library distances of zero for two nuclei, one for four, two for two, and three for one. This is too little complete-read ground truth to estimate full-field barcode accuracy reliably.

The final whole-image results are in `../popcrop_output/wellb2_002_002_manual_parity/run_summary_report.md` and its JSON manifest. These are algorithmic observations and assignments. A detected contour is a proposal; a classified signal is model evidence; an accepted library match passes the declared criteria. None alone proves biological truth. An apparently negative nucleus is not automatically untransduced. Full-field sensitivity and gene-assignment false discovery require representative reviewed nuclei, including weak, negative, mixed and off-library cases. The present fixes are supported by heldout annotation accuracy and explicit output checks, without claiming that all remaining distance-two or low-confidence reads are solved.

## Final run, 28 September 2026

Fresh segmentation found 5,376 nuclei. The detector proposed a contour in 5,371; the trained base model classified signal in 3,917 (72.9%). There were 2,491 accepted unique-gene assignments (46.3% of nuclei), spanning 464 genes, plus two accepted barcode sequences ambiguous between U2AF2 and LRP1B. These two observations match TCGCGGATATCG at distances zero and one.

The unique-gene assignments have selected-reference Hamming distances zero for 1,257 nuclei, one for 814, and two for 420. Across all signal-positive nuclei, nearest-reference distances are zero:1,264; one:859; two:732; three:704; four:358. Thus 2,123/3,917 (54.2%) of all signal-positive nuclei are within zero or one mismatch. The higher 83.1% zero-or-one rate within accepted unique-gene assignments must not be mistaken for the full-field rate. There remain 1,285 unmapped and 139 ambiguous signal-positive reads, alongside the two gene-ambiguous assignments.

The final full run took 169.46 seconds including fresh segmentation and export, with peak process RSS 4.51 GiB. The complete cycle table has 64,512 records. Independent validation recomputed every barcode reverse complement, selected and nearest Hamming distance, library tie, assignment gate, summary denominator and artifact hash. All 64,512 cycle records have consistent bases and normalized probabilities, and 106 sampled exact masks passed shape/area checks. The full regression suite passed 110 tests with three skips for unavailable optional fixtures; after the final export/serialization changes, the 48 affected integration and decoding tests also passed.

The per-cycle DAPI centering is identical to the annotator and explicitly recorded. A maximum shift above 13.75 px occurs in 4,022 nuclei, so LARGE_DAPI_RECENTERING is a review flag, not an assertion of correct tracking. The median maximum shift is 18.99 px. This may reflect local DAPI segmentation or touching nuclei as well as actual drift; improving biological identity tracking requires reviewing these cases rather than silently rewriting their barcodes. The representative diagnostic gallery now spans outcome classes and labels rejected references as candidates.

The original output remains untouched. Current nucleus calls are also provided as nucleus_barcode_calls.csv for convenient inspection. Detailed cycle data and masks remain in the losslessly compressed scientific outputs.
