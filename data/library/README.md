# Library inputs

`v4.3_library_barcodes.csv` is the unchanged reference library used by production and validation. The configured sequence column is `barcode_new`.

`designs/` preserves the seven original SnapGene `.dna` files and `v4.3_internal_mNG2_remodel.csv`. These are unique experimental-design source files, retained for reconstructing the experiment. Their barcode values overlap the reference library, but their additional design information is not redundant.
